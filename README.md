# Список покупок

Учебный сквозной проект на C++ и Qt Widgets.

## Что реализовано

- добавление и удаление товаров;
- проверка пустого названия и повторного добавления;
- сигналы и слоты для связи модели и интерфейса;
- подключение одного сигнала к нескольким обработчикам;
- таймер `QTimer`, который обновляет часы в интерфейсе раз в секунду;
- лямбда-слот таймера с контекстом `this`;
- динамическое переподключение сигнала `itemAdded`: уведомление можно выводить в строку состояния или в заголовок окна;
- хранение соединения в `QMetaObject::Connection` и его разрыв через `disconnect()`;
- дерево объектов Qt и автоматическое удаление дочерних виджетов;
- смена родителя поля ввода через `setParent()`;
- отложенное удаление временной панели через `deleteLater()`;
- наблюдение за временем жизни панели с помощью `QPointer`;
- сообщения о создании и уничтожении объектов через `qDebug()`.

## Сборка

1. Откройте `ShoppingList.pro` в Qt Creator.
2. Выберите установленный комплект Qt с модулем Widgets.
3. Соберите проект и запустите его.

Также проект можно собрать из терминала:

```bash
qmake ShoppingList.pro
make
```

## Структура

- `main.cpp` — запуск приложения;
- `mainwindow.h/.cpp` — графический интерфейс, таймер и динамическое соединение;
- `shoppinglistmodel.h/.cpp` — хранение товаров и проверка данных;
- `ShoppingList.pro` — настройки qmake.

Сборочные каталоги и пользовательские файлы Qt Creator исключены через `.gitignore`.
