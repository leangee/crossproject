# Список покупок

Учебный сквозной проект на C++ и Qt Widgets. Проект развивается по лабораторным работам: в него последовательно перенесены темы первой, второй и третьей лабораторных.

## Что добавлено по лабораторным

### Лабораторная №1 — сигналы, слоты и модель списка

- Модель `ShoppingListModel` унаследована от `QObject` и использует `Q_OBJECT`.
- Добавление и удаление товаров реализованы отдельными слотами модели.
- Проверяются пустое название и повторное добавление; ошибки передаются через сигнал `errorOccurred`.
- Сигналы `itemAdded`, `itemRemoved` и `itemCountChanged` сообщают интерфейсу об изменениях списка.
- Сигнал добавления подключён к нескольким обработчикам: обновление интерфейса и вывод сообщения в журнал отладки.

### Лабораторная №2 — дерево объектов и управление временем жизни

- Интерфейс списка покупок создан на Qt Widgets; можно добавлять и удалять товары.
- Поле ввода переносится между двумя панелями с помощью `setParent()`.
- Временная панель удаляется отложенно через `deleteLater()`.
- `QPointer` отслеживает, существует ли временная панель после запроса на удаление.
- Сообщения `qDebug()` показывают создание и уничтожение демонстрационных виджетов.

### Лабораторная №3 — QTimer, лямбда-слоты и динамические соединения

- `QTimer` обновляет часы в окне раз в секунду; обработчик подключён лямбда-функцией с контекстом `this`.
- Сигнал `itemAdded` динамически переподключается: уведомление о добавлении товара выводится либо в строку состояния, либо в заголовок окна.
- Соединение хранится в `QMetaObject::Connection`; перед созданием нового обработчика прежнее соединение разрывается через `disconnect()`.

## Сборка и запуск

1. Откройте `ShoppingList.pro` в Qt Creator.
2. Выберите установленный комплект Qt с модулем Widgets.
3. Соберите проект и запустите его.

Также проект можно собрать из терминала:

```bash
qmake ShoppingList.pro
make
```

## Структура проекта

- `main.cpp` — запуск приложения и цикл событий Qt;
- `mainwindow.h/.cpp` — интерфейс, демонстрация дерева объектов, таймер и динамическое соединение;
- `shoppinglistmodel.h/.cpp` — хранение товаров, проверки и сигналы модели;
- `ShoppingList.pro` — настройки qmake.

Сборочные каталоги и пользовательские файлы Qt Creator исключены через `.gitignore`.
